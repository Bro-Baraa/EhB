# Food Explorer

## About

Food Explorer is a single page web application made for the Advanced Web course.

The app uses TheMealDB API to display recipes from different countries and categories. Users can search for meals, filter the results, sort them and save their favorite meals.

The project was built with HTML, CSS, JavaScript and Vite.

## Features

- Browse meals from the API
- Search meals
- Filter by category and cuisine
- Sort meals
- View meal details
- Save favorite meals
- Dark and light mode
- Responsive layout

## Technologies

- HTML
- CSS
- JavaScript (ES6)
- Vite
- TheMealDB API
- LocalStorage

## API

This project uses TheMealDB API.

https://www.themealdb.com/api.php

The API is used to load meals, categories and recipe details.

## Installation

Clone the project:

```bash
git clone https://github.com/Bro-Baraa/EhB.git
```

Install the packages:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
